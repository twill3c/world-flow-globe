# 原典について

本プロジェクトの仕様の出所は、利用者から会話中に受領した Markdown 文書
**「WORLD FLOW GLOBE V3.2 — 完全実装仕様書」**(Version 3.2.0 / Status: Implementation Ready)である。

## この文書をリポジトリに収録していない理由

受領した実体は UTF-8 のバイト列が別の符号化として読まれた状態(いわゆる文字化け)で届いた。
本文を復元して収録することはできるが、**復元は一文字ずつの書き写しになり、
字形の近い別字種の混入(HC-072)を持ち込む経路になる**。
仕様の参照は節番号で足りるので、収録せず節番号の対応表だけを残す。

原典が必要になったときは利用者に再送を依頼すること。
